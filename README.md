# Meteor-Kommando

Weltraum-Spiel für Bruno, um das 1×1 spielerisch zu üben: Asteroiden mit Multiplikations-Aufgaben werden per Multiple-Choice-Antwort abgeschossen, jede Reihe (1er–10er) endet mit einem Boss-Kampf. Fortschritt (Sterne pro Reihe, freigeschaltete Reihen) wird lokal im Browser gespeichert.

Einfach `index.html` im Browser öffnen — kein Build-Schritt nötig.

**Live:** https://meteor-kommando.pages.dev

Neu deployen nach Änderungen: `npm run deploy` (benötigt `npx wrangler login` einmalig).

## Ideen für's Weiterbauen mit Bruno

- Neue Schiff- oder Boss-Skins
- Sound-Effekte (Laser, Explosion, Fanfare)
- Weitere Gegner-Typen pro Reihe
- Zwei-Spieler-Wettrennen-Modus
